# 개념도 이미지 폴더

여기에 **실제 교재 개념도 이미지**를 올리면, 토픽 설명(💡) 화면에서 mermaid 대신
그 이미지를 그대로 보여줍니다. (mermaid 재현이 원본과 다르던 문제 해결)

## 넣는 법

파일 이름을 **`<토픽id>.svg`** 또는 **`<토픽id>.png`** (또는 `.jpg`) 로 저장해 이 폴더에
올리면 끝. 코드 수정 불필요 — 해당 토픽 설명에서 자동으로 뜹니다.

- 우선순위: `.svg` → `.png` → `.jpg` → (없으면) mermaid 폴백
- 벡터(SVG)면 확대해도 선명합니다. 스캔/캡처는 PNG 권장.
- 파일이 없으면 지금처럼 mermaid 개념도가 나오고, 그것도 없으면 개념도 영역은 숨습니다.
