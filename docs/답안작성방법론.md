# 정보관리기술사 답안 작성 방법론 (요약)

출처: ITPE 기술사회 실전 답안 작성 방법론 (1교시 템플릿 / 2교시형 BP 방법론).
이 요약은 앱의 답안 생성 프롬프트(`src/lib/prompts.ts`)에 반영되어 있습니다.

## 공통 원칙 (1교시 = 2교시 동일)

- **(가장 중요) 출제 의도(Focusing)**: 문제가 "무엇을" 물었는지 정확히 파악해 그것만 답한다. 의도를 벗어나면 0점에 가깝다. 임의 해석·서브노트 나열 금지.
- **리드문(문제 요약)**: 답안 맨 앞에 `문 N)` 형식으로 물어본 것을 1~2줄 요약. 1교시는 토픽 Full Name 1줄. 요구사항 누락 금지.
- **목차 = 물어본 것**: 지문 표현(한글/영문)을 목차 제목에 그대로 노출. 누락은 감점/0점. 순서 임의 변경 주의.
- **정의 = "키워드 열거식" 2줄**: 문장으로 풀어쓰지 말고 핵심 키워드(기술요소·목적·특징)를 명사형으로 열거. 예) "OOO은 'A·B·C' 기반으로 'D'를 실현하는 'E' 기술". 한 줄 약 16~18자, 정의 전에 키워드 2~3개를 먼저 잡는다.
- **두음신공은 "나열 항목"에**: 구성요소·특징·원칙·절차처럼 여러 개를 나열하는 부분은 각 항목의 첫 글자(두음)를 모아 암기·제시한다(정의가 아니라 구성요소/특징 설명에서 활용).
- **강조**: 핵심 키워드 **굵게**(밑줄), 중요 용어 "큰따옴표". 두문자어(약어)는 풀어서 1회 설명.
- **일도일표(그림1·표1)**: 텍스트 개념도/구성도/아키텍처(4~6줄, 화살표) 1개 + 3단표 `| 구분 | 항목 | 설명 |` 1개. 비교문제는 비교표 `| 구분 | A | B |`.
- **간글**: 표·그림 바로 아래 **1줄**만 부연(길게 쓰지 말 것 — 1줄 외엔 버린다).
- **"답이 있는" 답안**: 물어본 것에 답한다. 답 없는 논리 나열·형식적 분량 채우기는 점수 없음. "왜 좋은지/큰지/효율적인지" 근거 포함.
- **차별화(+α)**: 마지막 단락에 최신 동향·실무/경험 사례·타 토픽 융합(Tailoring, 보통 2~3개 토픽)으로 깊이를 더한다.

## 1교시 (용어형, 3단락, 약 1.2~1.4페이지, 사실 중심)

| 단락 | 내용 |
| --- | --- |
| I. 개요 | 가. 정의 2줄(키워드 나열식) + 나. 특징/목적/등장배경 2줄 (III 충실 시 I-나 생략 가능) |
| II. 개념도/구성요소 | 가. 개념도(4~6줄)+간글 / 나. 3단표(구성요소·기술요소) |
| III. 활용/비교/고려 | 수직 확장·수평 연계·비교표·활용 사례 등 차별화 (7~8점 요소), 사실 중심 |

- 1문제당 약 10분, 10문제 = 약 13~14페이지. 추상적 기대효과 나열 지양.

### 1교시 채점 밴드 (참고)

| 점수 | 기준 |
| --- | --- |
| 6점 | 출제 의도 적합 + 정의 정확 + III단락 + 정확히 1.2p |
| 7점↑ | 위 충족 + 키워드 다수 노출 + 1.4p + 남보다 우수(상위 10%) |

## 2교시~4교시 (서술형, 4단락(IV), 약 3~3.5페이지)

| 단락 | 분량 | 내용 |
| --- | --- | --- |
| I. 서론 | 0.5p | 6가지 서론 타입 중 선택 |
| II. 본론1 | 1p | 물어본 요구사항(없으면 구성도+구성요소) |
| III. 본론2 | 1p | 물어본 요구사항(물어본 것 중심으로 풍부하게) |
| IV. 결론/α | 0.5p | 고려사항·기대효과·차별화 알파(17점 요소) |

- 단락별 1줄 띄우기(2교시형만), 문제당 2줄 띄우기.
- 1문제당 약 25분, 4문제 = 약 14페이지 목표. 잘 아는 문제부터 작성.

### 서론 6가지 타입

| 타입 | 설명 |
| --- | --- |
| Type I | 1교시 상속/확장 — 정의 2줄 + 특징(표) |
| Type II | 정의+특징을 그림/도식으로 (간글에 정의) |
| Type III | Why 관점 — 중요성·필요성 강조 |
| Type IV | 로드맵 — 물어본 가·나·다를 하나의 개념도로, Top-down |
| Type V | 병렬식 — 답이 명확한 다항 문제는 나열식 목차 |
| Type VI | 발전단계 — 순서·절차·기술 발전과정 |

## 채점 기준 (참고)

| 점수 | 기준 |
| --- | --- |
| 15점(상위 20%) | 출제 의도에 맞게 물어본 내용 1p 분량, 전체 3~3.5p, 그림·표 양호 |
| 16점(상위 5%) | 정확한 기술 + 상대적 키워드 노출, 3p 이상, 차별화 |
| 17점↑(상위 3%) | 위 충족 + 깊이 있는 알파(특강·신문·경험·타 토픽 응용), IV단락 0.5p 추가 |
